  • docs/pitch/intro-3pages.html:刪 .stat .v 和 .gain .v 兩條 text-shadow。其他 6px 小範圍 text-shadow(.pain-list li::before ✕ 符號、.stage::after → 箭頭)留著,實測沒有相同 artefact。

  • 第 1 頁(14天 / 30-50萬 / ×N輪)、第 3 頁(90秒 / -99% / 0 PII / ∞次)PDFKit 重繪後確認矩形消失,單位字完整可讀。
