應用方案 — How

一句話下達，六個 Agent 接力。

Claude API 串成五段管線、每段 streaming 回前端；N 位 persona 並行作答（worker pool concurrency = 6）， PM Plan / Summary / Report 全部開 thinking: adaptive， system prompt 一律 cache_control: ephemeral。

01 / ENTRY
需求驗證
把使用者一句話的 Brief 結構化，輸出 [STATUS:READY] 或追問。
stream · 1k tokens
02 / PM·PLAN
研究問題
產 4–6 題訪談題目 + 範圍與摘要。
adaptive · 4k · JSON
03 / PERSONA × N
並行訪談
N 位 AI 受訪者各自 streaming 第一人稱回答；五維人格分數即時計算。
parallel·6 · 1.5k each
04 / SUMMARY
洞察萃取
共識 / 分歧 / 風險 / metric 結構化萃取，含族群比較。
adaptive · 12k · JSON
05 / PM·REPORT
決策報告
關鍵發現、行動建議、優先序，前端可直接下載 PDF。
adaptive · 16k · JSON
  • 串流到底 — 每個 agent 都用 messages.stream()；前端用 SSE 同步看到打字動畫，不用等整段。
  • 並行 persona — Promise pool 控制併發 6，N 位 persona 在 60–90 秒內全部問完。
  • JSON 安全網 — json-extractor.ts 4 種候選擷取 × 6 種修補 × 24 次重試，模型偶爾回髒 JSON 也能自救。
  • 繁中口語護欄 — LANG_RULE 共享 prompt 焊進每支 agent；opencc-js 二次保險把簡轉繁，撥款 / 申辦等台灣詞鎖死。
  • 產品光譜可拖 — 算盤珠 slider 即時改變 persona 評分權重，UI 不重 fetch、純前端 reduce 重算 phase map。
  • 從零到 Demo — Claude Code 直接寫元件、寫 prompt、寫 SVG、寫 PDF 匯出 — 一個人就能跑完前後端。
